# Word Drop – Từ Rơi

Game web học từ vựng **tiếng Trung, Anh, Nhật, Hàn**. Từ vựng rơi từ trên xuống, chọn đúng nghĩa trước khi từ chạm đất.

A browser game for learning **Chinese, English, Japanese and Korean** vocabulary. Catch each falling word by picking its meaning before it hits the ground.

**Chơi ngay / Play:** https://nguyen16112006.github.io/word-drop/

## Tính năng / Features
- 4 ngôn ngữ để học: Trung (HSK 1–2), Anh (A1–A2), Nhật (N5), Hàn (TOPIK I)
- Giao diện Tiếng Việt hoặc English
- Phiên âm (pinyin, IPA, romaji, romanization) và phát âm bằng giọng đọc của trình duyệt
- Combo, tốc độ tăng dần, 3 mạng, kỷ lục theo từng ngôn ngữ và cấp độ
- Danh sách từ cần ôn sau mỗi ván
- Phím 1–4 để chọn, Space để tạm dừng; chơi được trên điện thoại
